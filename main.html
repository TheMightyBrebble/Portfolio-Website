Full Stack D&D Character Creator

When tasked with building a full stack application, my group decided on building a website that could allow users to build and develop their own Dungeons & Dragons characters. However, we put a spin on the creator to add our own flair as a group by adding a "element" group that allows some more personalisation to be added. We developed the front end using HTML and CSS for the design, then used JavaScript to allow for connection to the backend database. For the backend, it was coded solely using Java with MySQL being used to store the database. I was tasked with developing the "stats" section of the backend and for the front end, I was tasked with designing the layout for the character.
Technologies: Java - JavaScript - HTML - CSS - MySQL

Interactive JavaScript Web Game

I was tasked with developing a game developed solely within a website, while using JavaScript to help with features in the backend. I picked a quiz style game based on quiz shows such as Who Wants to Be a Millionaire? The idea was to store questions along with their options as objects in an array that the game goes through until it gets to the end. Each question has 4 options, an image and a correct answer attached which the program can recognise. The backend was also developed in a way that could allow for indefinite questions due to the nature of the array of objects.
Technologies: JavaScript - HTML - CSS

Java Based Two Player Card Game

I was tasked with developing a card game solely based around Java. This was done by developing classes that allowed the system to make and then shuffle a deck. The software was also able to remove one card from the deck at a time along with sorting the deck by suit or number order. Another feature added was the ability to play Snap using the newly created deck of cards. The feature allows the user to input 2 names on the main file and play snap based around 2 matching suits in a row. The turn player is then tasked with typing "snap" within 5 seconds otherwise the other player wins automatically.
Technologies: Java

Investigation into the usability of Games Console dashboards/in game menu screens

My third year project from Keele University. I tasked myself with research into the usability of games console dashboards and in game menu screens. I based a large amount of my research into how new users would approach current generation games console dashboards. This included studies about having users that were unfamiliar with the consoles perform simple tasks and timing to see how long it takes them to complete. Using these studies, I developed my own webpages using Figma before turning them into interactive websites and gathering opinions based on 3 prototypes. Using that, I developed a final dashboard designed with usability heuristics in mind.
Technologies: HTML - CSS - Figma
